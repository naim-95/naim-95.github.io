# Naim — Portfolio

Live site: **[naim-95.github.io](https://naim-95.github.io)**

Static portfolio built with **HTML**, **Tailwind CSS**, and **vanilla JavaScript**, highlighting work and academic projects across **Industrial IoT (ESP32, MQTT, Node-RED)**, **Android Development (Java, ZXing)**, and **Web/MySQL Systems**.

## Structure

* `index.html` — Main single-page datasheet portfolio with collapsible project modules and image lightbox
* `css/styles.css` — Custom drafting-grid styling and modal helpers
* `js/script.js` — Accordion state, clipboard copy, and full-size image viewer
* `Pictures/iot_images/` — Hardware and dashboard figures for the Air-Conditioning Performance Monitoring project
